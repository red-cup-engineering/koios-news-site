# Article media receiving

The October 26 content-quality direction requires a reader's article, its social
preview, structured image claim and syndication image to describe real published
media. The former builder selected opaque digest-grid fingerprints for these
surfaces and did not copy supplied image assets into its sealed output.

## Contract and ownership

The existing image owner receives only selected same-origin raster assets beneath
the admitted content root's `assets` directory. It rejects credentials, query or
fragment-bearing URLs, remote/private origins, traversal and escaping symlinks.
It never fetches an image or copies an unselected directory. Existing per-article
cards take precedence, then the accepted hero and the declared property default.
The effectful build entrance calls the original Sharp-backed card compositor only
when no selected editorial raster exists. That card states the article headline,
desk and publication; it makes no documentary claim and invokes no inference.

`buildPropertyWithMedia` and `buildConfiguredPropertyWithMedia` prepare measured
media before invoking the existing synchronous renderer. Existing synchronous
interfaces remain available. Media preparation binds the accepted manuscript's
digest and the selected original image bytes; the final rendering read must still
agree. It never writes to the manuscript, accepted publication ledger or input
assets. Selected image bytes and generated cards join the original build manifest
before sealing. Publication and deployment retain their original owners.

Article image schema, Open Graph, Twitter and feeds use those selected assets.
The effectful entrance measures width and height after EXIF orientation and
requires the decoder's format to agree with the published asset extension. The
synchronous entrance preserves selected existing bytes without asserting unknown
dimensions. A supplied hero's existing
alternative and credit remain attached to it; a headline graphic is visibly
identified. Fingerprint JSON/SVG/PNG artifacts remain available as provenance, but
are not asserted to be editorial imagery or used as an image fallback.

## Receiving

Original fixture builds cover a generated headline card with no documentary
image, preservation and sealing of actual credited hero bytes, an explicit
per-article card override, social/schema/feed correspondence, measured dimensions,
unchanged manuscripts, invalid/private image URLs, EXIF orientation, invalid
raster bytes or extensions, and changed-input refusal.
The synchronous no-raster case retains the truthful SVG and provenance without
inventing a raster image. Real photo commissioning, audio/video production,
immutable package publication, active application selection and public deployment
remain separate consumers; these tests cannot assert their completion. Inline
Markdown images retain their original renderer and are outside this selected
hero/card custody change.
